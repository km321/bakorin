Bakorin is a self-hosted backend you can spin up per client. Each project is one folder with one `app.yaml` and one database.

It is for agencies and solopreneurs who need auth, data, files, and an admin UI behind an Astro or Next.js site, without writing a custom API every time.

Describe the schema, run it locally, deploy the same project. The typed SDK talks to the API from your front end.

<Aside type="caution" title="Private beta">
Bakorin is in private beta. The npm packages (`create-bakorin`, `@bakorin/sdk`, `@bakorin/server`) are not published yet and the repository is private. Commands that use `npx` or `bunx` show the intended usage after publish. Until then, run everything from a checkout of the repository.
</Aside>

## What you get

- **Data and relations.** Entities with typed fields, relations with `onDelete` rules, indexes, filters, sorting, and `expand`.
- **Auth.** Email and password, email verification, password reset, invites, refresh token rotation, and lockout.
- **Permissions.** Per action policies such as `owner(ownerId)`, `authenticated`, `role(editor)`, and `admin`.
- **Files.** Uploads to local disk or S3 compatible storage, served by short lived signed URLs.
- **Webhooks.** Durable, signed, retried deliveries from an outbox table.
- **Jobs.** Cron schedules in `app.yaml`, handlers in `hooks.ts`, and an admin run history.
- **Admin UI.** Light and dark themes, tables, create and edit drawers, invites, backups, audit, webhooks, jobs, and a schema map.
- **Generated OpenAPI** at `/api/v1/openapi.json`, with Swagger UI at `/docs`.

## The stack

Bun, Hono, Kysely, and Zod on the server. A Preact admin UI embedded in the binary. SQLite by default, Postgres when you need more than one instance.

The packages in the repository:

| Package | What it is |
|---|---|
| `@bakorin/core` | Parses and validates `app.yaml`, compiles the schema, plans migrations, generates types |
| `@bakorin/server` | The HTTP server, CLI, migrators, auth, files, webhooks, jobs, backups |
| `@bakorin/admin-ui` | The Preact admin UI served at `/admin/` |
| `@bakorin/sdk` | Typed client, plus Astro and Next.js cookie helpers |
| `create-bakorin` | Scaffolds a project with an optional Astro or Next.js starter |

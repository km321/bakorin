# Contributing

Thanks for your interest in Bakorin.

## Contributor License Agreement

Outside contributions need a signed Contributor License Agreement (CLA) with Melton Studios before they can be merged.

## Licenses

The server packages (`packages/server`, `packages/core`, `packages/admin-ui`) are AGPL-3.0-only. The SDK, `create-bakorin`, and the examples and starters are MIT. See the License section of the README.

## Before you open a pull request

- Run `bun test` and make sure it passes.
- Keep changes focused, and describe what changed and why.
- Never commit secrets, API keys, or real `.env` files.

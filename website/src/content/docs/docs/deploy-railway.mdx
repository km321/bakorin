This works for a project scaffolded by `create-bakorin`, or any folder with `app.yaml`, `hooks.ts`, and the generated `Dockerfile`. Keep the git repo private until you choose otherwise.

<Aside type="note">
A one click Railway template is <span class="planned-badge">Planned</span>. Today you create the service yourself, which takes a few minutes.
</Aside>

## What to attach

1. One Railway service from the generated `Dockerfile`. `railway.json` and `railway.toml` already set the health check path to `/health`.
2. A volume mounted at `/data`, with `BAKORIN_DATA_DIR=/data`.
3. Optional: an S3 compatible Railway bucket for uploads and scheduled backups.

SQLite on the volume is the default. Postgres is optional: set `runtime.dialect: postgres` and `DATABASE_URL`.

## Steps

<Steps>

1. Create a service from the project (`railway up` from the project folder, or connect the private repo).

2. Add a volume and mount it at `/data`. Railway mounts the volume; the image does not declare a Docker `VOLUME`.

3. Set the required variables:

   | Variable | Value |
   |---|---|
   | `JWT_SECRET` | Long random string (required in production) |
   | `BAKORIN_DATA_DIR` | `/data` |
   | `CORS_ORIGINS` | Your Astro or Next.js origin. Comma separated if more than one |
   | `APP_URL` | Public URL of the front end |

   Railway injects `PORT`. Production refuses CORS `*`.

4. Optional: attach a bucket and set `S3_ADDRESSING_STYLE=path`. Railway buckets deny virtual hosted requests, and Bun's S3 client returns Access Denied without path style.

5. Optional first admin: set `BAKORIN_ADMIN_EMAIL` and `BAKORIN_ADMIN_PASSWORD` (at least 8 characters). Bakorin creates that admin only while no admin exists. You can also use **Create your first admin** at `/admin/`.

6. Deploy and confirm `GET /health` returns `{ "ok": true }`.

</Steps>

## Optional variables

| Variable | When |
|---|---|
| `MAIL_DRIVER` | `log` (default), `smtp`, or `resend` |
| `MAIL_FROM` | For Resend: `App Name <noreply@your-verified-domain.com>` |
| `RESEND_API_KEY` | Required when `MAIL_DRIVER=resend`. Set it as a Railway secret |
| `BUCKET` or `S3_BUCKET` | Turns on S3 files and `s3://` backups |
| `S3_ENDPOINT` or `AWS_ENDPOINT_URL` | Bucket endpoint |
| `S3_ACCESS_KEY` or `AWS_ACCESS_KEY_ID` | |
| `S3_SECRET_KEY` or `AWS_SECRET_ACCESS_KEY` | |
| `S3_REGION` or `AWS_DEFAULT_REGION` | Defaults to `auto` |

The full list is on [Configuration](/docs/configuration/).

<Aside type="caution">
Railway volume snapshots are a second copy, not a substitute for `bakorin backup` or scheduled S3 backups. See [Backup and restore](/docs/backups/).
</Aside>

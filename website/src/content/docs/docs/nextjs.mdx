`@bakorin/sdk/next` wraps the client and keeps tokens in `bakorin_access` and `bakorin_refresh` httpOnly cookies. It does not depend on `next` itself.

## Quick start

```bash
bun run create my-app --frontend next --schema todo --yes
```

The starter has the same pages as the Astro starter: signup, verify email, login, logout, forgot and reset password, accept invite, and a protected `/app`. Signup shows a "check your email" message and does not sign in.

## Client helper

```ts title="lib/bakorin.ts"
import { createNextClient } from "@bakorin/sdk/next";
import { cookies } from "next/headers";

export async function api() {
  return createNextClient({
    baseUrl: process.env.BAKORIN_URL ?? "http://127.0.0.1:4371",
    cookies: await cookies(),
  });
}
```

`cookies().set` only works in Server Actions and Route Handlers. Keep login and signup in `"use server"` actions so the SDK can write the token cookies.

```ts title="app/actions.ts"
"use server";

import { redirect } from "next/navigation";
import { api } from "../lib/bakorin";

export async function loginAction(formData: FormData) {
  const client = await api();
  await client.login({
    email: String(formData.get("email") ?? ""),
    password: String(formData.get("password") ?? ""),
  });
  redirect("/app");
}
```

## Protect a route

```ts title="middleware.ts"
import { NextResponse, type NextRequest } from "next/server";

export async function middleware(request: NextRequest) {
  const token = request.cookies.get("bakorin_access")?.value;
  if (!token) return NextResponse.redirect(new URL("/login", request.url));
  const base = process.env.BAKORIN_URL ?? "http://127.0.0.1:4371";
  const me = await fetch(new URL("/api/v1/auth/me", base), {
    headers: { authorization: `Bearer ${token}` },
  });
  if (!me.ok) return NextResponse.redirect(new URL("/login", request.url));
  return NextResponse.next();
}

export const config = { matcher: ["/app/:path*"] };
```

## Browser calls and live updates

For client components, add the pass through route. Client code calls `/api/bakorin/...` on your own site, and the route forwards to Bakorin with the httpOnly session cookies.

```ts title="app/api/bakorin/[...path]/route.ts"
import { createNextProxy } from "@bakorin/sdk/next";

export const dynamic = "force-dynamic";
export const { GET, POST, PATCH, PUT, DELETE } = createNextProxy({
  baseUrl: process.env.BAKORIN_URL ?? "http://127.0.0.1:4371",
});
```

```tsx title="app/app/live-tasks.tsx"
"use client";
import { useEffect } from "react";
import { createBrowserClient } from "@bakorin/sdk/browser";

export function LiveTasks() {
  useEffect(() => createBrowserClient().subscribe("tasks", (change) => {
    // update local state from change.op, change.id, change.record
  }), []);
  return null;
}
```

The route refreshes expired tokens, turns auth responses into cookies, refuses writes from other sites (403 without a matching `Origin`), and streams [realtime](/docs/realtime/) events. The options are the same as the [Astro route](/docs/astro/#browser-calls-and-live-updates). The starter's `/app` page uses it for a live task list with a done toggle.

## Settings

- Set `CORS_ORIGINS` on the API to the Next.js origin (`http://localhost:3000` locally).
- Set `APP_URL` on the API to the Next.js origin for email links.
- Set `BAKORIN_URL` in the Next.js app if the API is elsewhere.

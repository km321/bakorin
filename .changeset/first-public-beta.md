First public beta. Bakorin turns one app.yaml into a self hosted API with auth, CRUD, files, realtime, mail, jobs, webhooks, and an admin UI (@bakorin/server and @bakorin/core), a typed client with Astro and Next.js helpers and components (@bakorin/sdk), and a project generator with blog, marketing, SaaS, and store templates (create-bakorin).
